# 📊 사내 데이터 분석 AI Agent 개발 진행 현황

본 문서는 사내 데이터 분석 및 리포팅 자동화 AI Agent 프로젝트의 주요 개발 실적과 트러블슈팅 내역을 요약합니다.

## 1. 핵심 아키텍처 및 클린 모듈 분리
- **설정 및 상태 관리 분리:** `config.py`, `state.py`, `visualizer.py`로 핵심 로직을 분리하여 유지보수성을 극대화.
- **다중 파일 확장자 파싱 안정화:** CSV, 다중 시트 엑셀, 워드 문서를 자동 분류하며, Pandas 3.0 환경의 `NaN` 오류와 엑셀 기본 테마 색상 오탐지 현상을 완벽히 차단.

## 2. 파이썬 선(先) 계산을 통한 AI 환각 차단
- **전수 미기입 ID 명단 기록:** AI에게 숫자 계산을 맡기지 않고, 파이썬이 전체 행을 스캔하여 '컬럼별 미기입 실제 TC ID 명단'을 100% 산출해 프롬프트에 주입. 
- **사내 기준(%) 자동 판정:** 불량률 등 사내 품질 기준값 초과 여부를 파이썬 IF/ELSE 로직으로 확정 지어 `🚨 확인 필요` 또는 `✅ 이상 없음` 배너를 리포트에 강제 부착.

## 3. [중요] 대용량 데이터 토큰 한도 최적화 및 RAG 연동
- **초강력 프롬프트 다이어트(Chunking):** 수백 건의 엑셀 업로드 시 Groq 무료 API 등에서 발생하는 토큰 한도 초과(413, 429 에러)를 방지하기 위해, 전송 샘플을 **'핵심 열 10개, 최대 3~5건, 셀당 20자 이내'**로 강제 압축.
- **사내 지식 RAG(검색 증강 생성) 연동:** 사내 점검 기준서나 과거 회의록(Word/TXT) 업로드 시 텍스트를 추출하여 LLM에 지식(Knowledge)으로 주입, 사내 규정을 인용한 정확한 조치 제안 작성 가능.

## 4. 실무 맞춤형 산출물 및 UI/UX
- **마스터 엑셀 & 페이지 분리형 워드 추출:** 모델별 비교표, 한글 기초통계, 막대 차트가 내장된 엑셀(`.xlsx`)과 빈 페이지 없는 깔끔한 워드(`.docx`) 자동 추출.
- **자유 스크롤 플로팅 팝업 채팅:** 대시보드 화면 잠금 없이 1·2·3번 시각화 차트를 위아래로 휠 스크롤하며 대화할 수 있는 후속 질문 팝업창 탑재.
