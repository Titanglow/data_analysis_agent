## 2. W47 주요 개발 및 트러블슈팅 완료 내역

### ① 클린 아키텍처 3대 모듈 분리 리팩토링 (`config.py`, `state.py`, `visualizer.py`)
- `data_agent/config.py`: 테마 색상(`#059669`), 고대비 차트 팔레트, 사내 기본 품질 기준값(`1.5%`), 모델 라벨 상수 분리
- `data_agent/state.py`: LangGraph 노드 간 공유 상태(`AgentState`) 스키마 분리 및 `graph.py` 연동
- `data_agent/tools/visualizer.py`: 양식 자동 검증 배너, 4대 핵심 KPI 카드, 가로형 TOP 순위 차트, 유사 제목 시나리오 그룹핑 차트 로직 분리

### ② 다중 파일 확장자별 자동 분류 및 파싱 안정화 (`app.py`, `data_loader.py`)
- **다중 파일 첨부·분류·초기화:** CSV, Excel(`.xlsx`), Word(`.docx`), TXT 다중 첨부 시 확장자별(`📊Excel` / `📈CSV` / `📄Word` / `📝TXT`) 자동 분류 묶음 표시, 개별 선택 또는 2개 이상 동시 병합 분석, **원클릭 전체 파일·입력 초기화 버튼** 구현
- **트러블슈팅:** Pandas 3.0 환경의 `NaN(float)` 정규식 충돌(`TypeError: expected string or bytes-like object, got 'float'`)을 `_safe_str()` 방어 로직으로 원천 차단하고, 엑셀 기본 테마 색상이 강조 색상으로 오탐지되던 문제 수정

### ③ 전체 데이터 조회 복원 · 컬럼별 미기입 TC ID 전수 추출 · 핀셋 SQL (`excel_exporter.py`, `app.py`)
- **전체 건수 조회 & 핀셋 SQL:** 기본 조회 시 100건 제한(`LIMIT 100`)을 해제해 전체 건수(예: 592건/63건 전체)를 100% 조회하도록 복원하고, `_detect_mentioned_columns()`를 통해 **`Expected Result 미기입`**, **`Procedure 미기입`**, 부분 키워드(`VP9`, `배달`), 제외(`빼고/제외`), 정렬(`ORDER BY`)을 정확히 변환
- **미기입 TC ID 전수 명단 추출:** 파이썬이 전체 행을 전수 스캔하여 각 컬럼의 미기입 건수뿐만 아니라 **실제 미기입 `TC ID(Title)` 전수 명단**을 한글 기초통계표에 직접 기록함으로써, AI가 샘플(상위 15건) 밖의 항목을 "알 수 없다"고 답하던 한계 해결

### ④ 실시간 5단계 파이프라인 & 무환각 리포트 정제 (`app.py`, `reporter_node.py`, `llm.py`)
- **실시간 1~5단계 파이프라인 배지:** 분석 실행 중 `🔄 AI 병렬 분석 중...` 실시간 상태 전환, 분석 완료 시 4·5번 초록색 완료(`✅`) 전환, 파일 교체 시 자동 리셋 구현
- **리포트 품질 정제 및 끊김 방지:** `Auto_RTC` 접두사를 자동화로 오판하던 오류, `525%` 수치 붙음 및 `<br>` 노출, 원본에 없는 항목 환각을 차단. 출력 토큰 여유(`2,200`) 확보 및 `5.`/`6.` 원본 샘플 행 나열(Groq Echo 끊김) 자동 절단 안전장치 적용

### ⑤ 마스터 엑셀(`.xlsx`) 정제 & 페이지 분리형 워드(`.docx`) 자동 추출 (`excel_exporter.py`)
- **엑셀 정제:** 분석 일시(`YYYY-MM-DD HH:MM:SS`) 및 적용 기준값(`threshold%`) 자동 판정 요약 기록, 가독성이 떨어지던 불필요 막대차트 2종 제거
- **워드(`.docx`) 보고서 자동화:** 외부 패키지 없이 OpenXML로 생성. **1페이지(종합 요약 및 '확인 필요' 사항 + AI별 핵심 비교 요약표)**와 **2페이지 이후(각 AI 모델별 독립 페이지 시작)**로 구성하고, `<w:pageBreakBefore/>` 속성으로 중간 및 말미 **빈 페이지(Blank Page) 0건** 보장

### ⑥ 1·2·3번 자유 스크롤 플로팅 팝업 채팅방(A) & 3회 반복 상세 검증기(C) (`app.py`)
- **💬 대화형 후속 질문 채팅방(Chatflow):** `🔒 Local: Ollama` 기본 단독 구동을 지원하며, 우측 플로팅 팝업 모드 활성화 시 하단 4번 채팅방은 자동 일시중지되고 **배경 화면 잠금 없이 마우스 휠로 1번(표)·2번(그래프 차트)·3번(리포트)을 자유롭게 스크롤**하며 대화 가능
- **🔁 3회 반복 실행 '일관성 vs 차이점' 상세 비교기:** 단순 글자 수 비교를 넘어 1~3회차 단락별 실제 출력 내용 비교표, 3회 모두 유지된 핵심 수치 vs 표현 차이점을 자동 진단하고 **파트회의 공유용 워드(`.docx`) 문서**로 원클릭 다운로드 제공

### ⑦ UI/UX 테마 비교 검증 및 최종 확정 (`config.py`, `app.py`)
- 노션(Notion) 워크스페이스 스타일 테마 스위치를 구현·검토한 결과, 데이터 차트 및 상태 배지 시인성 면에서 기존 **에메랄드 그린(`#059669`) 대시보드 UI**가 우수하다고 판단하여 테마 스위치를 깔끔하게 롤백하고 에메랄드 UI로 최종 확정
