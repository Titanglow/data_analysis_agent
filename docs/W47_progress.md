## 2. W47 주요 개발 및 트러블슈팅 완료 내역

### ① 클린 아키텍처 3대 모듈 분리 및 다중 파일 파싱 (`config.py`, `visualizer.py`, `data_loader.py`)
- 설정/테마 모듈 분리 및 Excel/CSV/Word 다중 첨부 시 확장자별 자동 분류 구현.
- **트러블슈팅:** Pandas 3.0 환경의 `NaN(float)` 정규식 충돌을 `_safe_str()`로 차단하고, 엑셀 기본 테마 색상이 강조 색상으로 오탐지되던 문제 수정.

### ② 미기입 TC ID 전수 추출 및 컬럼별 핀셋 SQL (`excel_exporter.py`, `app.py`)
- **전수 미기입 ID 명단 기록:** 파이썬이 600건 이상 전체 행을 전수 스캔하여 각 컬럼의 미기입된 실제 `TC ID(Title)` 전수 명단을 통계표에 기록함으로써, AI가 샘플 밖 항목을 누락하는 현상 해결.
- **컬럼 핀셋 필터링:** `Procedure 미기입`, `Expected Result 미기입` 등 특정 컬럼의 공란 조회 시 타 컬럼의 `N/A`와 섞이지 않고 해당 컬럼만 정확히 추출하는 검색 로직 적용.

### ③ [중요] 대용량 데이터 토큰 한도 초과(413, 429 에러) 원천 해결 (`llm.py`, `app.py`)
- **원인:** 500건 이상의 대용량 엑셀 데이터 분석 시, 프롬프트 용량이 Groq 무료 API의 분당 토큰(ITPM/OTPM) 제한을 2배 이상 초과하여 서버 거절 발생.
- **해결 (초강력 다이어트):** AI에 전송하는 샘플 데이터를 **'핵심 열 10개, 최대 3~5건, 셀당 20자 이내'**로 강제 압축(Chunking)하여 프롬프트 토큰 크기를 획기적으로 줄임. 또한, 안정적이고 한도가 넉넉한 `llama-3.3-70b-versatile` 모델로 고정하여 끊김 현상 해소.

### ④ 마스터 엑셀 정제 & 페이지 분리형 워드(`.docx`) 추출 (`excel_exporter.py`)
- **워드(`.docx`) 보고서 자동화:** 외부 패키지 없이 OpenXML로 생성. **1페이지(종합 요약 및 3대 AI 요약표)**와 **2페이지 이후(각 모델별 독립 페이지)**로 나누고, `<w:pageBreakBefore/>`를 적용해 **빈 페이지(Blank Page) 0건** 보장.

### ⑤ 자유 스크롤 플로팅 팝업 채팅(A) & 3회 일관성 검증기(C) (`app.py`)
- **플로팅 팝업 채팅방:** 로컬 Ollama 구동 지원. 우측 팝업 모드 실행 시 **배경 화면 잠금 없이 마우스 휠로 1번(표)·2번(차트)·3번(리포트)을 위아래로 자유롭게 스크롤하며 대화** 가능.
