# [W48] 사내 데이터 분석 Agent - 실무 투입 안정화 및 RAG 고도화

## 🎯 이번 주 핵심 목표 (11.23 ~ 11.27)
1. **사내 지식(RAG) 연동:** 단순 수치 해석을 넘어 사내 규정과 회의록을 기반으로 조치 제안을 작성하는 무환각(Zero-Hallucination) AI 구현.
2. **실전 데이터 스트레스 테스트:** 부서 내 예외가 많은 악성 엑셀(병합 셀, 빈칸, 타입 꼬임 등) 업로드 시 발생하는 파이썬 에러 원천 차단.
3. **사용자 경험(UX) 극대화:** 보고서 작성 흐름을 끊지 않는 플로팅(Floating) 팝업 채팅방 및 마스터 엑셀 자동화.

## 🚀 주요 개발 및 적용 사항

### 1. RAG (검색 증강 생성) 기반 사내 규정 연동
- **기능:** 사이드바에 사내 품질 점검 기준서 및 회의록(Word, TXT)을 추가 업로드할 수 있는 RAG 전용 uploader 구축.
- **효과:** AI가 3번 리포트(원인 진단 및 조치 제안) 작성 시, 일반적인 조언이 아닌 **"제1조 규정에 따라 24시간 내 QA 파트장 보고"** 등 실무 맞춤형 지시사항을 강제 인용하여 환각(거짓말)을 완벽 차단.

### 2. 악성 데이터 스트레스 테스트 및 방어벽(Exception Handling) 구축
- **버그 픽스 1 (`IndexError`):** 결측치(NaN)나 공란이 대부분인 컬럼에서 최빈값을 추출할 때 발생하는 판다스(Pandas) 인덱스 참조 에러 해결.
- **버그 픽스 2 (`TypeError`):** 텍스트와 실수(float)가 혼재된 병합 셀 데이터를 자연어로 검색할 때 발생하는 데이터 타입 충돌 현상을 순수 파이썬 `str()` 매핑으로 완벽 우회.
- 스레드 안정성 개선: 긴 분석 시간 대기 중 터미널(Ctrl+C) 강제 종료가 먹히지 않던 현상을 해결하기 위해 스레드(Thread) 종료 방식(as_completed 활용) 개선
### 3. 멀티 LLM 엔진 최적화 및 503 에러 우회
- **Groq 엔진 안정화:** Groq 클라우드에서 수시로 퇴출당하는 모델(llama3-70b-8192 등)을 제외하고, 가장 최신의 대형 모델(`llama-3.3-70b-versatile`, `mixtral-8x7b-32768`)로 강제 고정하여 404 에러 방지.
- **Gemini 엔진 우회:** 무료 토큰 한도(Rate Limit) 및 글로벌 서버 과부하로 인한 `503 UNAVAILABLE` 에러 발생 시, 흉한 에러를 뱉지 않고 사용자에게 1분 후 재시도 안내를 하는 방어 로직 추가.
- **Ollama 로컬 엔진 Timeout 연장:** 무거운 사내 문서를 읽어 들이는 시간(Context Reading)을 고려하여 로컬 호출 타임아웃을 180초에서 600초(10분)로 넉넉하게 연장.

### 4. 대화형 팝업 채팅(Chatflow) 도입
- **기능:** 에이전트 분석 결과(3번 리포트)를 보며 자유롭게 마우스 휠을 스크롤할 수 있도록 우측 하단에 **플로팅(Floating) 팝업 메신저 UI** 도입.
- **연동:** 팝업창 내의 빠른 칩(예: "컬럼별 미기입 TC ID 명단") 클릭 시, 1번(원본 데이터)과 2번(통계표)을 메모리에서 즉시 불러와 100% 매칭되는 ID 명단을 즉석 답변.
- 팝업 채팅방의 대화 내역을 .txt 파일로 즉시 내보내는 기능 탑재

### 5. UI 업데이트 
- **색깔모드:** : "☀️ 화이트 모드 / 🌙 다크 모드" 화면 테마 변경 라디오 위젯 구현
