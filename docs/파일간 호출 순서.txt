   │  ├─ build_smart_sql()          : 전체조회 / 컬럼별 미기입 핀셋 추출(Expected Result 미기입 등) / 부분 키워드 / 정렬 SQL 변환

   │  └─ build_korean_stat_tables() : [excel_exporter.py] 전체 행 전수 스캔으로 '컬럼별 미기입 실제 TC ID 명단' 및 한글 통계표 생성
   ▼

   ▼
